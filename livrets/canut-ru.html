Телевизор

Смарт-ТВ Android 43". Используйте приложение Molotov TV для доступа к французским каналам.

🍳

Варочная панель

Сенсорная стеклокерамическая плита. Нажимайте на кнопки для регулировки мощности от 1 до 9. Блокировка от детей: длительное нажатие на кнопку блокировки.

🌡️

Отопление

Умные радиаторы, автоматически установленные на 19-20°C. Электрический обогреватель доступен в гостиной для дополнительного комфорта.

🛏️

Постельное белье

Простыни и полотенца готовы к использованию для всех кроватей.

🪟

Жалюзи спальни

Чтобы закрыть жалюзи спальни, откройте окно и используйте ручную рукоятку.

💡

Выключатель гостиной

Выключатель света гостиной находится между двумя буфетами, рядом с входом.

🧺

Стиральная машина-сушилка

Комбинированная стирка + сушка. ⚠️ Объем белья для сушки не может быть таким же, как для стирки. Дополнительная сушилка в другом помещении зарезервирована для персонала уборки.

🛋️

Диван гостиной

Диван не предназначен для сна. Он предназначен только для сидения. Спасибо за соблюдение этого правила.

📋

Правила дома

Некурящее помещение (датчик CO2 · не отключайте · подключённая сигнализация) · без животных · без вечеринок · тишина после 22:00. Датчик шума и камера на площадке.
